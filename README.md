# منهاجي

تطبيق تعليمي للطلاب السوريين — دروس بالفيديو، بنك أسئلة، وامتحانات تجريبية
ووزارية. يعمل **دون إنترنت**، ويُحوَّل إلى APK عبر Capacitor.

HTML + CSS + JavaScript عادي. **بلا إطار عمل وبلا خطوة بناء.**

---

## التشغيل

**أسرع طريقة:** انقر نقرًا مزدوجًا على `index.html`.

تعمل كل الشاشات مباشرةً. الوحيد الذي لا يعمل على `file://` هو الـ service
worker (يحتاج `http`)، فللتجربة الكاملة كـ PWA:

```powershell
cd C:\Users\Agha\Desktop\manhaji
npx serve .
```

ثم افتح العنوان الذي يظهر. على الهاتف: افتح نفس العنوان من نفس الشبكة، وستجد
خيار «إضافة إلى الشاشة الرئيسية».

**تسجيل الدخول للتجربة** — اسم مستخدم (٣ أحرف فأكثر) + أحد هذه الأكواد:

| الكود | النتيجة |
|---|---|
| `FR97K3M` | اشتراك الصف التاسع |
| `F12A4XQ` | اشتراك البكالوريا |
| `FR9USED` | كود مرتبط بجهاز آخر (حالة الخطأ) |

## نموذج الدخول: بلا بريد وبلا كلمة مرور

الدخول باسم مستخدم + كود تفعيل فقط، والاشتراك يفتح على **جهاز واحد**.

**هذا هو كامل النموذج الأمني:** الكود بمثابة كلمة السر، وربطه بجهاز واحد هو ما
يمنع تداوله بين الطلاب. كود مسرَّب بلا ربط جهاز = اشتراك واحد يستعمله فصل كامل.

اسم المستخدم **ليس عنصر حماية** — الكود وحده فريد ويحمل المادة والصف. دور
الاسم هو العرض داخل التطبيق والبحث في الدعم الفني.

> ⚠️ **النتيجة التي يجب أن تُدار تشغيليًا:** لا يوجد استرداد ذاتي. حين ينكسر
> هاتف الطالب أو يعيد ضبطه، يبقى الكود مرتبطًا بالجهاز القديم ويُقفل الطالب
> خارج اشتراكه المدفوع. **يجب أن يملك الموزّع أو الأدمن أداة فكّ ارتباط** —
> وإلا تحوّل كل هاتف مكسور إلى شكوى ومبلغ مستردّ.
>
> واجهة التطبيق تشير إلى هذا المسار في شاشة الدخول وفي «حسابي»، لكن الأداة
> نفسها تُبنى في لوحة الأدمن.

## ثلاثة أجهزة، تخطيط واحد

| الجهاز | العرض | التخطيط |
|---|---|---|
| هاتف | < 700px | عمود واحد · تنقّل هرمي بزر الرجوع |
| لوحي | 700–1099px | عمود أوسع · بطاقات في شبكات ثنائية |
| حاسوب | ≥ 1100px | **شريط تنقّل جانبي ثابت** + محتوى محدود العرض |

القرار الحاكم: **حدّ عرض القراءة.** النص العربي عند 16px يصبح متعبًا فوق نحو
٧٠ محرفًا في السطر، لذلك لا يمتد المحتوى بعرض شاشة الحاسوب — يُحدّ بـ `68ch`
للنص و`820px` للبطاقات. الشاشات ذات العمودين (الدروس + الامتحانات، الامتحان +
شبكة التنقّل) تأخذ `1060px` لأن أعمدتها منفصلة أصلًا.

على الحاسوب يختفي زر الرجوع من الترويسة: الشريط الجانبي يقوم بالتنقّل، وزرّان
للرجوع في آنٍ واحد يربكان لا يساعدان.

## أربع قواعد لا تُكسر

1. **لا `innerHTML` لإعادة الرسم.** نبني عُقد DOM. كل الإدخال في التمارين
   **أزرار** لا حقول نصية، فإعادة البناء الكامل آمنة ولا تفقد تركيز مؤشر.
   الاستثناء الوحيد `prose` (نص الدرس) — محتوى ثابت من بياناتنا.

2. **معادلة الإتقان مكرّرة عمدًا في مكانين:**
   `js/store.js → recordAttempt()` و `supabase/migrations/…_progress.sql →
   tg_apply_topic_mastery`. أي تعديل يجب أن يطبَّق في الاثنين، وإلا قفز مؤشر
   التقدّم عند عودة الإنترنت.

3. **الـ service worker يخزّن الهيكل فقط.** المحتوى وتقدّم الطالب مكانهما
   قاعدة البيانات المحلية. الخلط يُنشئ مصدرَي حقيقة يتعارضان.

4. **وضع الأوفلاين حالة طبيعية لا خطأ.** لافتته زرقاء معلوماتية تطمئن، لا
   حمراء تحذّر.

### ٢. الربط بـ Supabase
الباك اند جاهز في `C:\Users\Agha\syria-edu\supabase` (الجداول، RLS، دوال
التفعيل والمزامنة). يبقى استبدال `js/data/seed.js` بطبقة `js/data/`:
`db.js` (SQLite) · `sync.js` (outbox) · `entitlement.js` (التفعيل).

### ٣. التحويل إلى APK

```powershell
npm init -y
npm i @capacitor/core @capacitor/cli @capacitor/android
npx cap init "منهاجي" com.manhaji.app --web-dir=.
npx cap add android
npx cap sync
npx cap open android      # يفتح Android Studio لبناء الـ APK
```

Capacitor ينسخ المجلد كما هو — لا خطوة بناء ولا تحويل.

بعد إضافة أندرويد أضف `@capacitor/device` للحصول على معرّف جهاز مستقر
(ربط كود التفعيل بجهازين)، و`@capacitor-community/sqlite` لقاعدة بيانات
أصلية بلا حدود تخزين المتصفح.
